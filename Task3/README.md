# Данные, масштабирование и отказоустойчивость

* Спроектирована стратегия работы с данными в микросервисной архитектуре
* Обеспечена масштабируемость и отказоустойчивость хранилищ.

Структура каталога:

* `database-strategy.md` — выбор базы данных для каждого сервиса;
* `scaling.md` — стратегии репликации и шардирования;
* `caching.md` — дизайн кэширования;
* `event-streaming.md` — архитектура Kafka;
* `diagrams/` — диаграммы данных.
