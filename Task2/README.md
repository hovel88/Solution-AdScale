# Проектирование RTB и интеграции с DSP

* Спроектирована архитектура критичного компонента — RTB-сервиса для интеграции с новой DSP-площадкой с соблюдением требований по времени отклика и надёжности.

Структура каталога:

* `bidding-service.md` — спецификация сервиса ставок;
* `interaction.md` — схема взаимодействия с обоснованием выбора протоколов;
* `api-gateway.md` — дизайн API Gateway для DSP;
* `diagrams/` — диаграммы взаимодействия (sequence, component).
