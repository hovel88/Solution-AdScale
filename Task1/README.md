# Архитектурная диагностика и целевое видение

* Проведён анализ текущей архитектуры
* Выявлены проблемы и риски
* Разработана целевое архитектурное видение
* Задокументированы ключевые решения через ADR

Структура каталога:

* `as-is.md` — анализом текущей архитектуры;
* `drivers.md` — архитектурные драйверы;
* `to-be.md` — описанием целевой архитектуры;
* `diagrams/` — диаграммы C4 в формате PlantUML или DrawIO;
* `adr/` — документы ADR.
